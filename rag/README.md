# RAG Workflows

Retrieval-Augmented Generation pipelines for building and querying AI knowledge bases. These workflows use locally-run Ollama embeddings and Supabase vector storage — no external embedding APIs required.

| Workflow | Level | Description |
|----------|-------|-------------|
| [seed-supabase-from-notion](./seed-supabase-from-notion/) | Intermediate | Ingest Notion pages into a Supabase vector store |
| [multi-kb-agentic-rag-assistant](./multi-kb-agentic-rag-assistant/) | Advanced | AI agent that queries multiple knowledge bases and cites sources |
