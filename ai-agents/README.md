# AI Agent Workflows

Agentic workflows that reason, select tools, and act autonomously. These range from a production-grade customer support system to a conversational Slack bot.

| Workflow | Level | Description |
|----------|-------|-------------|
| [autonomous-customer-support-agent](./autonomous-customer-support-agent/) | Advanced | 50-node production agent with multi-KB RAG, confidence routing, and human escalation |
| [slack-gemini-agent](./slack-gemini-agent/) | Intermediate | Gemini-powered Slack bot with weather, news, stock, Wikipedia, and calculator tools |
| [gmail-ai-triage](./gmail-ai-triage/) | Intermediate | AI agent that classifies unread emails and applies Gmail labels or marks as read |
